# LeftPad キー割り当て（Clip Studio Paint iPad想定）

## ボタン（BUTTON_0〜9）

| ボタン | 送信 | クリスタでの意味（イラスト制作） |
|---|---|---|
| BUTTON_0 | P | **ペン系ツール**に切替（ペン/鉛筆グループ） |
| BUTTON_1 | M | **選択範囲ツール**に切替（投げ縄/矩形など） |
| BUTTON_2 | E | **消しゴム**に切替 |
| BUTTON_3 | ⌘+Z | **取り消し（Undo）** |
| BUTTON_4 | ⌘+T | **変形（拡大・縮小・回転）** |
| BUTTON_5 | ⌘+D | **選択を解除（Deselect）** |
| BUTTON_6 | ↑ | **微調整移動（nudge）**：選択中のレイヤー/オブジェクト/選択範囲を上へ |
| BUTTON_7 | ← | **微調整移動（nudge）**：左へ |
| BUTTON_8 | → | **微調整移動（nudge）**：右へ |
| BUTTON_9 | ↓ | **微調整移動（nudge）**：下へ |

## ロータリーエンコーダ

| 操作 | 送信 | クリスタでの意味（イラスト制作） |
|---|---|---|
| 反時計回り | [ | **ブラシサイズを小さく**（小さいプリセットへ） |
| 時計回り | ] | **ブラシサイズを大きく**（大きいプリセットへ） |
